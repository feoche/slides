Titre : Design System : 'Tout ça pour des couleurs' ?

Description :
Derrière un Design System, on imagine souvent 3-4 couleurs qui se battent en duel qui actent le ton d'une interface Web. Pourtant, dès qu'on creuse la surface, on découvre une mine d'atouts qui révèlent toute sa puissance.

Ce talk est le récit d'un parcours semé de défis techniques, de politiques inter-équipes et de choix de gouvernance qui façonnent un Design System vivant.

L'objectif de ce talk est de vous donner les clés pour trouver le juste équilibre entre contraintes techniques, rigueur et créativité — sans sombrer dans des heures de débats sur le choix du nouveau bleu pourpre pâle.
